```

Use "main" branch of the associated GitHub Repo, for the GitHub Action and file updates. 
If the GitHub Action program is good for another day (daily routine use), leave it in the "main" branch. Otherwise delete it after used.

Wait for a random minutes:seconds. The random time waiting program is waitForRandomTime.js.

Create new stories and task on https://dev.azure.com/cubeforest3003/ , under Project "powerBI-demo".
```

# Close work items:
```
This is a daily routine job for Azure Devlop Work Item's management.

Manage the stories and tasks on https://dev.azure.com/cubeforest3003/ , under Project "powerBI-demo".

Use "main" branch of the associated GitHub Repo, for the GitHub Action and file updates. 
If the GitHub Action program is good for another day (daily routine use), leave it in the "main" branch. Otherwise delete it after used.

Wait for a random minutes:seconds. The random time waiting program is waitForRandomTime.js.

From "main" branch of the associated github project, found the user story ID and task ID created in the morning in it README.md. 

Close these user stories and tasks.

After closed the stories and tasks, update the state "Closed" of the affected stories and tasks in README.md on the "main" branch.
```
